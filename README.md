# ✈️ British Airways Reviews Dashboard

An interactive Tableau dashboard project analyzing British Airways customer reviews to uncover passenger satisfaction trends, service quality insights, and travel experience patterns.

---

## 📌 Project Overview

This project focuses on analyzing customer review data of British Airways using Tableau.  
The dashboard provides meaningful insights into passenger experiences, helping identify trends related to customer satisfaction, cabin service, comfort, entertainment, and overall travel experience.

The goal of this project is to transform raw review data into an easy-to-understand and visually appealing dashboard for better business decision-making.

---

## 📊 Dashboard Features

- Overall Customer Satisfaction Analysis
- Cabin Staff Service Ratings
- Seat Comfort & Food Ratings
- Entertainment Experience Analysis
- Traveler Type & Cabin Class Insights
- Interactive Filters & Dynamic Visualizations
- Trend Analysis of Customer Reviews

---
